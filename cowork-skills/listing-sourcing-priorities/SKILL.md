# ⛔⛔⛔⛔ ИСТОЧНИК СПРОСА ДЛЯ ТАРГЕТА ДНЯ — ПЕРЕХОДНЫЙ РЕЖИМ (владелец, 03.10.2026)

03.10.2026 запущена новая форма Meta: бюджет мелкими шагами (до 25 / 25-30 / 30-35 / 35-40 / 40-50 / 50-70 / 70+), плюс фичи (green flags / red flags) в форме и тот же вопрос про фичи в первом сообщении. Лиды по старой форме (бюджет «30-50» и т.п.) неточные.

## До 17.10.2026 включительно
**Окно «лиды за 14 дней» из CRM для таргета НЕ использовать.** Спрос берётся из фиксированной аналитики за 2 месяца (раздел 1 ниже). Предложение — живой каталог сайта на сегодня, как обычно. Кофф и дефицит считаются по `bali-demand-matrix`, только доли спроса — отсюда.

Фиксированные доли спроса (из 175 клиентов, «2-3» и «1-2/1+кабинет» разнесены пополам):

| Спальни | Доля | Потолок цены (приоритет) |
|---|---|---|
| 2BR | ~53% | 35-40M (медиана 32M) |
| 3BR | ~24% | 45-50M (медиана 48M) |
| 1BR / 1+кабинет | ~20% | 30M (медиана 30M) |
| 4BR+ | ~3% | не искать активно |

| Район | Доля |
|---|---|
| Пояс Seseh (Seseh + Cemagi + Munggu) | ~31% |
| Pererenan | ~26% |
| Canggu | ~25% |
| Umalas | ~8% |
| Berawa | ~5% |
| Seminyak | ~5% |
| Uluwatu | не искать |

Доля ячейки спальни × район = произведение долей. Бюджет ячейки — потолок из таблицы спален.

**Фичи — приоритет внутри ячейки** (порядок по частоте запроса): сад → просторно (метраж) → тихо, без стройки → **современный стиль (обязательно модерн, не joglo/балийский open-air)** → закрытая гостиная → питомцы → рабочее место → закрытая кухня → безопасно для детей. Виллы с подтверждёнными фичами — первыми в план и в первое касание; явное «против» — в конец очереди. Не гейт.

## С 18.10.2026
Спрос — лиды CRM начиная с 03.10.2026 (только новая форма), окно 14 дней:
- **базовый запрос** (спальни, район, бюджет) — из ответов формы;
- **фичи** — из ответов клиента на первое сообщение (green / red flags) и из формы;
- лиды старой формы (до 03.10) в куб не брать.
Каждый день мониторить ответы на первое сообщение и считать спрос на фичи по ячейкам: «сколько клиентов ячейки просят сад / модерн / закрытую кухню / питомцев…» против «сколько вилл ячейки это имеют».

В отчёте прогона первой строкой: `DEMAND SOURCE: fixed 2-month analytics (until 17.10)` или `DEMAND SOURCE: new-form leads since 03.10, 14-day window`.

# Приоритеты поиска листингов — решения владельца 03.10.2026

Читать ВМЕСТЕ с `bali-catalog-sourcing-rule`, `listing-card-standard`, `bali-demand-matrix`, `listing-qualification-standard`. При конфликте прав этот скил.

| 31-35M | 13 |
| 36-40M | 21 |
| 41-50M | 10 |
| 51-60M | 7 |

- 74% хотят до 40M. Медиана: 1BR 30M, 2BR 32M, 3BR 48M.
- **Спрос против каталога:** 2BR — у 63% спроса бюджет до 35M, в каталоге 2BR до 35M только 22%. 3BR — у 72% спроса до 50M, а 52% вилл 3BR в каталоге дороже 55M. **Каталог дороже спроса.**

## 2. Вторая линия — главное направление поиска

Логика владельца: дорога **Jl. By Pass Tanah Lot** делит Canggu / Pererenan / Seseh на две зоны.

- **Зона 1 — у океана (юг дороги):** туристы, short term, дороже всего, много посуточных, владельцы часто не сдают на год (отказы Frost, Lestari, Kana-ya, Unna, Sin Nombre — отсюда).
- **Зона 2 — вторая линия (север дороги):** резидентская зона, её выбирают экспаты под long term. Дешевле, участки больше, чаще сад, тише, меньше туристов. В разговоре её часто тоже называют «Canggu» / «Seseh», если она параллельна.

Замер 03.10.2026: из 99 живых арендных листингов **89 у океана, 10 за дорогой**. Запросы прогонов 25.09-03.10 шли почти только по прибрежным улицам (Batu Bolong, Echo Beach, Pantai Seseh, Pantai Cemagi…). В реестре пинов Tumbak Bayuh 16, Dalung 3 — против Canggu 569.

**Правила:**
1. Зона 2 — приоритетная. Искать там: север Canggu, Pererenan выше Jl. Raya, Tumbak Bayuh, Babakan, Buduk, Kayu Tulang, Dalung, север Padonan, Tegal Jaya, Munggu Kaja, Abianbase, Umalas, Kerobokan.
2. Искать **сеткой точек** (Places `searchNearby` по координатам к северу от дороги), а не только названиями районов — Google под «Canggu» отдаёт пляжные посуточные.
3. Граница — линия дороги по координатам (примерно от -8.6226,115.1231 до -8.6396,115.1641; уточнять по карте). В каждой карточке и листинге помечать `ZONE: ocean side / second line`.
4. Спрос и предложение считать **отдельно по каждой зоне**.
5. Зона 1 не бросать: короткие сроки (треть спроса) лучше закрываются виллами у океана с помесячной ценой.

## 3. Ценовой потолок — ПРИОРИТЕТ, НЕ ФИЛЬТР

Владелец 03.10.2026: «брать конечно, тут скорее вопрос приоритета».

- Первыми в план дня и в первое касание: **2BR до 35-40M, 3BR до 45-50M** (1BR — ориентир медиана 30M).
- Дорогие виллы тоже заводим (контакт уже оплачен), но они в конце очереди и пишем им во вторую очередь.
- Ценовая минималка из `listing-qualification-standard` (с допуском 15%) остаётся.
- В отчёте: сколько карточек в потолке, сколько выше.

## 4. Каналы — порядок

1. **Пины Google Maps — основной канал.**
2. **Instagram — второй.**
3. **FB — только посты самих владельцев, не агентов.** Агент = сплит комиссии, не канал.

Фильтр на входе в FB (владелец 03.10.2026): **западное имя автора — достаточный предфильтр, чтобы завести карточку.** Это не доказательство, а сито. Окончательно «владелец или агент» уточняет WhatsApp-бот при первом касании — первым вопросом.

Дополнительные сигналы владельца (усиливают, не обязательны):
- явное «I am the owner», «owner direct», «no agent», «saya pemilik», «langsung pemilik» — заводить и при местном имени;
- у автора одна вилла, а не поток разных объектов;
- нет логотипа агентства и «DM for more options»;
- номер не встречается в других объявлениях разных вилл.

Явные признаки агента (много разных объектов, агентский бренд) — не заводить.
Бот ответил «agent» — карточку закрыть с причиной `agent, not owner`.

Автозадача `fb-rental-demand-scout` ищет **арендаторов**, а не владельцев — это другой процесс.

## 5. Первое касание — 5 обязательных вопросов

Кроме спален, цены (с позицией по 10% комиссии) и доступности, спрашивать:
1. Можно ли с питомцами?
2. Гостиная закрытая или открытая?
3. Кухня закрытая или открытая?
4. Есть ли забор / ограждение у бассейна (дети)?
5. Есть ли стройка рядом?
Плюс метраж виллы и участка. Для карточек из FB первым вопросом — владелец или агент. Ответы — в поля `tenant-priority-criteria` и в `property_private.notes` с источником «owner».

## 6. Инспекции

Из 49 вилл с Google-пинов проинспектировано только 5. Каждый день давать Юди список ближайших друг к другу непроинспектированных вилл (по 3 на выезд), чтобы правда о вилле шла от нас, а не из интернета.

## 7. Форма Meta (запущена 03.10.2026)

Бюджет: до 25 / 25-30 / 30-35 / 35-40 / 40-50 / 50-70 / 70+. Спальни: 1 / 1+кабинет / 2 / 3 / 4+. Фичи green flags / red flags — в форме и дублируются в первом сообщении. Предложения на будущее: районы — несколько, убрать Uluwatu, «Other» → поле ввода, вариант второй линии («Canggu — quiet residential, further from beach», Tumbak Bayuh, Babakan, Buduk, Kayu Tulang); «Вы сейчас на Бали?»; «Номер WhatsApp, если отличается» (около 28 платных лидов пришли без WhatsApp).
