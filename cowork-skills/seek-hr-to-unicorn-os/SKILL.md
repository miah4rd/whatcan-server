# SEEK → Unicorn OS (HR)

## Цель
Каждый новый отклик на вакансию на SEEK = карточка в HR → New в Unicorn OS.
Владелец открывает карточку и за 5 секунд понимает: **кто это, что делал, где живёт** — и одним кликом открывает резюме на SEEK.
Кандидатам НЕ писать, статусы на SEEK НЕ менять, никого НЕ отклонять, апгрейды SEEK НЕ покупать.

## Инструменты
- **Unicorn OS — только через коннектор Unicorn OS (MCP).** create_lead, add_note, crm_request. Ключ открывает HR (91000001) и Rental Listings (11180334). amoCRM не трогать.
- **SEEK — Chrome (Claude in Chrome), рабочий профиль, залогинен.** Своя вкладка; закрыть все свои вкладки в конце, даже при ошибке.

## Шаги
1. **Дедуп.** `GET /api/v4/leads?filter[statuses][0][pipeline_id]=91000001&filter[statuses][0][status_id]=91000011` (+ другие стадии HR при необходимости). Сравнить по имени и телефону. Если HR пустая — обработать все отклики (backfill), иначе — только новые.
2. **Список откликов.** Открыть `https://id.employer.seek.com/candidates/?jobid=<JOBID>`. ID откликов взять со страницы: элементы с `aria-controls` = UUID (+ суффикс `-rr`, его отрезать); имя — ближайший родитель с текстом «Applied …».
3. **Профиль кандидата.** Открывать НАВИГАЦИЕЙ, не кликом: `…/candidates/?jobid=<JOBID>&selected=<UUID>&tab=profile`. Из диалога `[role=dialog]` взять: имя, телефон (+62…), email, город, карьеру (должность — компания — даты), образование, ответы на скрининг-вопросы (блок «Application questions» виден в тексте профиля), вкладки.
4. **Сопроводительное.** Если есть вкладка «Cover Letter» — `…&tab=cover-letter`, текст после «Notes and attachments». CV — `…&tab=resume`, текст тоже читается; смотреть его при фильтре.
4a. **ФИЛЬТР НА ВХОДЕ (владелец, 30.09.2026).** Карточку создаём ТОЛЬКО если в карьере (SEEK-профиль, CV или сопроводительное) есть хоть какой-то реальный опыт **в недвижимости на Бали, в нише аренды** — хотя бы одно из:
   - агент / консультант / маркетинг / листинги в агентстве недвижимости или аренды на Бали;
   - leasing, rental agent, property/listing manager, работа с арендаторами или владельцами;
   - property management / управление арендными виллами на Бали (villa manager арендных вилл, компании вроде Ministry of Villas, Bali Super Host и т.п.).
   Long-term приоритетнее, но не обязателен; должность, стаж и район НЕ проверяем — фильтр базовый, не узкий.
   **НЕ проходит:** только отели/курорты, F&B, customer service, продажи другого (авто, финансы, IT), административка, опыт вне Бали без недвижимости.
   **Самоотчёт на скрининге** («Experience as a Rental Agent: 5 years») без подтверждения в истории/CV — НЕ считается; при сомнении открыть CV.
   Не прошедших — не заносить, только посчитать в отчёте (имя + одна причина). На SEEK ничего не делать (не отклонять).
5. **Карточка.** `create_lead`:
   ```json
   {"name":"<Имя как на SEEK>","pipeline_id":91000001,"status_id":91000011,
    "_embedded":{"contacts":[{"name":"<Имя>","custom_fields_values":[
      {"field_code":"PHONE","values":[{"value":"+62…","enum_code":"WORK"}]},
      {"field_code":"EMAIL","values":[{"value":"…","enum_code":"WORK"}]}]}]}}
   ```
6. **Заметка** (`add_note`) — ПЕРВЫЕ СТРОКИ = то, что видно на SEEK, без пересказа своими словами:
   ```
   SEEK: https://id.employer.seek.com/candidates/?jobid=<JOBID>&selected=<UUID>&tab=profile
   CV:   https://id.employer.seek.com/candidates/?jobid=<JOBID>&selected=<UUID>&tab=resume
   <Текущая должность> at <Компания> (<стаж>) · <Город> · <Образование, год>
   Screening: work rights … · Rental agent: … · Villa manager: …
   ---
   Experience:
   - <Должность> — <Компания> (<даты, стаж>)   ← до 6 строк, как на SEEK
   Education: …
   Email: …
   Cover letter: <текст как есть, до ~700 символов или "none attached">
   Applied: <дата> on SEEK
   Vacancy: <название>, SEEK job <JOBID>
   ```
   Строка «должность at компания (стаж) · город · образование» — это ровно шапка карточки кандидата в списке SEEK, копировать её дословно.
7. **Проверка.** Повторный GET по стадии New: все созданные карточки на месте, у каждой есть заметка (`GET /api/v4/leads/<id>/notes`). При 5xx — сначала проверить, не создалось ли, потом повторять (без дублей).

## Подводные камни (проверено 30.09.2026)
- **Скрытая вкладка = SEEK не рисует профиль.** Если `document.visibilityState === 'hidden'`, клики по карточкам не открывают диалог, таймеры тормозят до 1/мин. Решение: работать в окне, которое создал `tabs_context_mcp{createIfEmpty:true}`, и открывать профили навигацией по URL с `selected=`. Не запускать долгие async-циклы внутри страницы.
- Первая строка диалога бывает инициалом-аватаром («K», «S») — пропускать строки длиной ≤2.
- Вывод javascript_tool, где есть query-строка URL, блокируется — выводить только UUID, URL собирать из проверенного jobid и UUID.
- Просмотр профиля снимает отметку «New» в инбоксе SEEK — это нормально, статус не меняется.
- Кнопка «→» в диалоге SEEK = «Move to a status». НЕ нажимать.
- **Отображение в Unicorn OS:** боковая панель карточки (Copilot / Overview / History) на 30.09.2026 заметки НЕ показывает, а строка под именем на доске («request not read yet») берётся из поля `summary`, которое генерирует сам OS. Заметки через API сохраняются, но владелец их в интерфейсе не видит, пока OS не выведет заметки или summary для HR. Если это поменяется — саммари класть туда, где его видно.

## Отчёт (коротко, факты)
- Новых откликов с прошлого прогона: N
- Прошли фильтр → созданы карточки: имена (+ id, чем подходит — одна строка)
- Отсеяны фильтром: M (имя — причина одной фразой)
- Если новых нет — одна строка «No new applicants».
