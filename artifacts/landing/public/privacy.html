Privacy Policy

Effective: July 30, 2026

Data Collection

The WhatCan Copilot extension does not collect, store, or transmit any personal data. All data processing occurs through the copilot server API at copilot.globalapplab.ru, which the user's organization operates and controls.

Permissions

The extension requests certain browser permissions solely to display the copilot interface within the amoCRM lead detail page and to deliver desktop notifications. No data is sent to third parties.
